# Source and differences

Adapted from [Slate's iconography skill](https://github.com/prabinpebam/slate/blob/d594742a1a6582c5cb890fcb18e63bc798ced99e/visualization/skills/iconography/SKILL.md),
at commit `d594742a1a6582c5cb890fcb18e63bc798ced99e`.

Keeps semantic selection, one-source consistency, geometry provenance, accessibility
and theme checks. Removes Slate-specific manifests, preinstalled font paths and
assumptions that the host already supplies licenses. No other skill is required.

No icons, fonts or third-party artwork are included. Source-library licenses must be
checked for every chosen asset. Slate itself declares no project license at this
revision; `NOASSERTION` records this, not permission to redistribute the kit.
