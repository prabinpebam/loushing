# Source and adaptation

This is an independent, self-contained adaptation maintained in Loushing, not a
sync-generated upstream copy. It can be installed without the source kit, its
installer, other skills, agents or project configuration.

The canonical skill and templates were copied first. The skill now includes its
own complete grounding, risk, success and experience procedure instead of
requiring sibling skill routing. Installer and project-facts dependencies were
removed; default artifact locations and a standalone completion check were added.
The catalog card and this provenance file are Loushing additions.
