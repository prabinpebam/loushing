# Source and differences

Adapted from [Slate's chart skill](https://github.com/prabinpebam/slate/blob/d594742a1a6582c5cb890fcb18e63bc798ced99e/visualization/skills/chart/SKILL.md),
at commit `d594742a1a6582c5cb890fcb18e63bc798ced99e`.

Keeps truthful encodings, provenance, accessible data, theme awareness and rendered
review. The original uses Slate's Semiotic server renderer; this version deliberately
does not bundle that dependency or claim its supported-chart surface or automated
validation. It uses existing project tooling or transparent simple SVG geometry.

Independently maintained; no Slate, Semiotic or other skill is required. Slate has no
declared license at this revision. `NOASSERTION` is not a reuse license; check with
the owner before reuse. No renderer or third-party assets are copied.
