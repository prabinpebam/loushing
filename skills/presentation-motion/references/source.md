# Source and differences

Adapted from [Slate Presentation Motion](https://github.com/prabinpebam/slate/blob/d594742a1a6582c5cb890fcb18e63bc798ced99e/presentation/motion/SKILL.md),
canonical skill name `slate-presentation-motion`, at commit
`d594742a1a6582c5cb890fcb18e63bc798ced99e`.

Keeps visual mechanisms, meaningful holds, semantic fragments, interruption and
reduced-motion review. Replaces Slate recipes, manifest schemas, validators and
runtime commands with a host-neutral state/control contract. It is an independent
authoring workflow, not an extracted or compatible Slate animation engine.

No other skill, Slate checkout, runtime or dependency is required to follow it.
Implementation needs access to the target deck/player source. The source kit declares
no license at this revision; `NOASSERTION` is not permission to redistribute it.
