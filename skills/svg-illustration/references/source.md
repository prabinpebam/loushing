# Source and differences

Adapted from [Slate SVG Illustration](https://github.com/prabinpebam/slate/blob/d594742a1a6582c5cb890fcb18e63bc798ced99e/visualization/skills/svg-illustration/SKILL.md),
canonical skill name `slate-svg-illustration`, at commit
`d594742a1a6582c5cb890fcb18e63bc798ced99e`.

Keeps semantic composition, three-box collision geometry, text-fit and safe-area
contracts, accessibility, provenance and rendered inspection. Replaces Slate-only
profiles, attributes, validators and mandatory viewport motion with ordinary SVG
and actual host capabilities. The visual brief is bundled locally.

This independently maintained version needs no Slate checkout or other skill and
does not promise Slate's automated validation. No third-party art is bundled.

reuse license. Check with the owner before reuse.
